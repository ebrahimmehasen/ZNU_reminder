# مواعيدنا

كالندر مواعيد مشترك لمجموعة صغيرة. أي حد معاه لينك الموقع يقدر يضيف ويعدّل ويمسح أي معاد، والتذكير بيوصل لجروب تليجرام كل يوم الصبح.

- **مفيش تسجيل دخول.** اللينك هو المفتاح، فابعتوه للناس اللي تثقوا فيهم بس.
- كل معاد بيتبعت للجروب أول ما حد يضيفه.
- كل يوم الصبح بتوصل رسالة واحدة فيها مواعيد **النهارده** و**بكرة** و**بعد 3 أيام**، ومعاها المناسبات المصرية.
- المناسبات الهجرية (رمضان، العيدين، …) **تواريخها تقريبية**، لأن مصر بتحدد اليوم بالرؤية وممكن يفرق يوم.

---

## الإعداد خطوة بخطوة

دي حاجات لازم تعملها بنفسك، لأنها محتاجة حساباتك.

### 1. قاعدة البيانات (Supabase)

1. ادخل على [supabase.com](https://supabase.com) واعمل مشروع جديد (الخطة المجانية كفاية).
2. من القائمة اختار **SQL Editor**، والصق كل اللي في ملف `supabase/schema.sql`، ودوس **Run**. لو شغلته أكتر من مرة مفيش مشكلة.
3. من **Project Settings → API** انسخ:
   - **Project URL**: ده `SUPABASE_URL`
   - مفتاح **service_role** (مش الـ anon): ده `SUPABASE_SERVICE_ROLE_KEY`

> ⚠️ مفتاح الـ service_role سري جدًا: ما تحطوش في أي مكان غير إعدادات Vercel، وما تبعتوش لحد.

### 2. البوت (Telegram)

1. في تليجرام ابعت لـ **@BotFather** الأمر `/newbot`، واختار اسم ويوزرنيم للبوت.
2. هيبعتلك **token** شكله كده `123456789:AA...`: ده `TELEGRAM_BOT_TOKEN`.

### 3. الجروب

1. اعمل جروب تليجرام جديد (أو استخدم جروب موجود).
2. ضيف البوت للجروب.
3. ابعت أي رسالة في الجروب.

### 4. رقم الجروب (chat id)

1. افتح في المتصفح (حط التوكن بتاعك مكان `<TOKEN>`):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
2. دوّر على `"chat":{"id":-100...` اللي جنبه اسم الجروب. الرقم السالب ده هو `TELEGRAM_CHAT_ID`، وانسخه بالسالب.
3. لو اللي ظهر `"result":[]` (فاضي):
   - ابعت رسالة تانية في الجروب واعمل refresh.
   - لو لسه فاضي: ابعت `/setprivacy` لـ @BotFather، واختار البوت، واختار **Disable**، وبعدها ابعت رسالة في الجروب تاني. أو اعمل منشن للبوت في الرسالة (`@اسم_البوت`).

### 5. الرفع على Vercel

1. ارفع المشروع على GitHub، وبعدين من [vercel.com](https://vercel.com) اعمل **Add New → Project** واختاره.
2. في **Environment Variables** ضيف الخمس متغيرات دول:

| الاسم | القيمة |
|---|---|
| `SUPABASE_URL` | من خطوة 1 |
| `SUPABASE_SERVICE_ROLE_KEY` | من خطوة 1 |
| `TELEGRAM_BOT_TOKEN` | من خطوة 2 |
| `TELEGRAM_CHAT_ID` | من خطوة 4 (بالسالب) |
| `CRON_SECRET` | أي كلام عشوائي طويل، مثلًا ناتج `openssl rand -hex 32` |

3. دوس **Deploy**.

> ما تكتبش أي اسم من دول بـ `NEXT_PUBLIC_` في الأول.

### 6. جرّب التنبيه

افتح الموقع ودوس **«جرّب التنبيه»** فوق. لازم توصل رسالة «البوت شغّال» في الجروب. لو ظهر خطأ، الرسالة هتقولك السبب (مثلًا `chat not found` معناها إن الـ chat id غلط أو البوت مش في الجروب).

### 7. شوف تذكير حقيقي

ضيف معاد النهارده أو بكرة، وافتح:

```
https://<موقعك>.vercel.app/api/cron?key=<CRON_SECRET>&force=1
```

هيبعت رسالة التذكير للجروب حالًا. من غير `force=1` مش هيبعت غير مرة واحدة في اليوم.

## التذكير اليومي بيشتغل إزاي

- Vercel Cron بيفتح `/api/cron` كل يوم الساعة `05:00 UTC` (متظبطة في `vercel.json`)، يعني **8 الصبح في الصيف و7 الصبح في الشتا** بتوقيت مصر.
- على خطة Vercel المجانية (Hobby) الـ cron بيشتغل مرة واحدة في اليوم بالكتير، **وممكن يتأخر لحد ساعة** (مثلًا 8:40 بدل 8:00).
- لو مفيش حاجة النهارده أو بكرة أو بعد 3 أيام، **مش هيتبعت حاجة**.
- لو الـ cron اشتغل مرتين في نفس اليوم، الرسالة **مش هتتكرر**: جدول `reminder_runs` بيسجل إن رسالة اليوم اتبعتت.
- لو تليجرام فشل، التسجيل بيتمسح، فلو فتحت `/api/cron?key=...` تاني هيحاول يبعت من جديد.
- ميزة جانبية: الطلب اليومي ده بيمنع Supabase إنه يوقف المشروع المجاني بسبب عدم الاستخدام.

## المناسبات المصرية

بتتحسب في الكود لأي سنة، ومش محتاجة تتضاف لقاعدة البيانات:

- **تواريخ ثابتة:** رأس السنة، عيد الميلاد المجيد، 25 يناير، عيد الأم، تحرير سيناء، عيد العمال، 30 يونيو، 23 يوليو، 6 أكتوبر.
- **عيد القيامة وشم النسيم:** بيتحسبوا بالتقويم القبطي.
- **هجري (تقريبي):** رأس السنة الهجرية، المولد النبوي، أول رمضان، عيد الفطر، وقفة عرفات، عيد الأضحى. أيام العيد التانية بتظهر في الكالندر بس من غير تذكير.

الإجازات الرسمية لونها أحمر، والمناسبات التانية (زي عيد الأم) لونها بني، والتاريخ التقريبي عليه علامة ≈.

## للتطوير

```bash
npm install
cp .env.example .env.local   # واملأ القيم
npm run dev                  # http://localhost:3000
npm test                     # اختبارات المنطق (تواريخ، مناسبات، رسايل)
npm run build
```

### هيكل المشروع

```
app/
  page.js                 صفحة الكالندر (الصفحة الوحيدة)
  EventForm.js            نموذج إضافة/تعديل معاد
  api/events/             GET قائمة، POST إضافة (+ رسالة للجروب)
  api/events/[id]/        PUT تعديل، DELETE مسح
  api/cron/               التذكير اليومي
  api/telegram/test/      رسالة تجريبية
lib/
  dates.js                التواريخ (بدون شبكة)، و"النهارده" بتوقيت القاهرة
  holidays.js             المناسبات المصرية
  reminders.js            بناء رسايل تليجرام وتقسيمها
  calendar.js             تجهيز أيام الشهر وقائمة «الجاي قريب»
  validate.js             التحقق من بيانات المعاد
  supabase.js             اتصال قاعدة البيانات (على السيرفر بس)
  telegram.js             إرسال رسايل تليجرام (على السيرفر بس)
supabase/schema.sql
tests/
```

المتصفح عمره ما بيكلم Supabase مباشرةً. كل حاجة بتعدي على الـ API بتاع الموقع، والـ RLS شغال من غير أي policies.
